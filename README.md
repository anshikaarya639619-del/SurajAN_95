# EVERYTHING WORLD

A global knowledge platform for education, travel, skills, science, technology, culture, and everyday life.

## MVP
- Mobile-first website
- Hindi and English first
- Useful, original, reviewed content
- Search and SEO foundations
- Free tools first; no paid services without explicit approval

## Truth-first
No website can be guaranteed to rank #1 for every Google search. We will measure real search performance and improve based on evidence.
